# GeoShan
A cool terminal-based weahter application written in **Go**

GeoShan can get weather information for a city you provide, or automatic detect your location when no city is specified

![GeoShan](assests/readme.png)

## Features
- Search weather by city name
- Automatic location detection
- Styled terminal

## Installation

Binaries are avaliable on Releases page
Linux
Windows

## Build for own
Clone the repo ¯\\_(ツ)_/¯
```
git clone https://github.com/shantanuparte/GeoShan.git
```

Build the binaries

```
go build -o geoshan .
```

## Usage

GeoShan has 2 features 

 ```./geoshan Pune``` 
 or for spaced names 
 ```./geoshan "New York"```

Also you can run it without arguments: 

```./geoshan```

When no city is provided it determines your location automatically
